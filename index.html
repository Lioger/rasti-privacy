Политика конфиденциальности

Действует с 17 октября 2026 года. Обновлена 20 октября 2026 года.

1. Общие положения

Настоящая Политика конфиденциальности описывает использование и хранение информации в мобильном приложении «Расти» (далее — «Приложение»).

Разработчик Приложения — Степанов Никита Владимирович, физическое лицо.

Приложение предназначено для ведения домашнего каталога детской одежды.

2. Какие данные используются

Пользователь самостоятельно добавляет в Приложение:

  • имя или обозначение ребёнка, его текущий размер и, по желанию, рост;
  • сведения об одежде: категории, размеры, количество и характеристики;
  • фотографии вещей;
  • заметки и пользовательские теги.

Дата рождения, пол, адрес и контактные данные ребёнка не запрашиваются отдельными полями. Для работы Приложения не требуется учётная запись.

Приложение также создаёт локальные служебные записи, необходимые для хранения гардероба, работы настроек, восстановления удалённых вещей и импорта файлов.

Пользователь может самостоятельно указать дополнительную информацию в заметках и тегах. Все эти сведения используются для работы функций Приложения.

3. Хранение данных

Информация о гардеробе и добавленные фотографии хранятся локально на устройстве пользователя.

Приложение не требует регистрации или создания учётной записи.

Гардеробы не загружаются на сервер разработчика. Автоматическая облачная синхронизация не предусмотрена.

4. Передача гардероба и резервные копии

Пользователь может самостоятельно передать гардероб другому человеку, создать резервную копию или импортировать ранее сохранённый файл.

«Передать гардероб». Пользователь выбирает одного или нескольких детей, чей гардероб хочет передать. Если профиль ребёнка только один, Приложение сразу подготавливает файл.

Созданный ZIP-файл содержит выбранные профили, их действующие вещи, характеристики, заметки, связанные теги и доступные фотографии. Вещи из раздела «Удалённые» в такой файл не включаются.

После подготовки файла открывается системное меню, в котором пользователь самостоятельно выбирает, кому и через какое приложение передать архив.

«Резервная копия». Приложение создаёт ZIP-файл со всеми профилями детей, их действующими и удалёнными вещами, фотографиями и тегами. Пользователь самостоятельно выбирает папку для сохранения.

«Импортировать гардероб». Пользователь выбирает поддерживаемый ZIP-файл. Перед импортом Приложение показывает его состав. При совпадении имён профилей можно выбрать объединение, перезапись или пропуск импорта.

Экспортируемые ZIP-файлы не защищены отдельным паролем и не шифруются средствами Приложения.

При передаче или сохранении файла через стороннее приложение дальнейшая обработка информации зависит от выбранного пользователем сервиса. Разработчик не получает эти файлы автоматически.

Передача и резервное копирование выполняются по инициативе пользователя. Автоматического обновления сохранённых файлов и синхронизации гардеробов между устройствами нет.

5. Фотографии и разрешения

Пользователь может выбрать фотографию вещи из галереи устройства или сделать снимок камерой. Добавление фотографии необязательно.

Разрешение на использование камеры запрашивается при попытке сделать снимок. Доступ к фотографиям предоставляется в соответствии с механизмами операционной системы устройства.

Выбранные фотографии обрабатываются и сохраняются локально в хранилище Приложения. При добавлении нового снимка выполняются обрезка и уменьшение изображения для удобного хранения.

Оригинальные фотографии в галерее пользователя Приложение не удаляет и не заменяет.

6. Аналитика и реклама

Приложение не использует рекламные сети, инструменты аналитики и технологии отслеживания действий пользователей.

Данные гардероба не используются разработчиком для рекламы, профилирования или маркетинговых рассылок.

7. Сроки хранения и удаление данных

Данные гардероба хранятся локально, пока пользователь не удалит их или данные самого Приложения.

При удалении отдельной вещи она перемещается в раздел «Удалённые вещи», откуда её можно восстановить. Автоматическая очистка этого раздела не предусмотрена.

При удалении профиля ребёнка удаляются его вещи, включая находящиеся в разделе «Удалённые». Другие профили при этом не удаляются.

Фотографии очищаются из хранилища Приложения, когда больше не используются другими записями. При технической ошибке очистка может выполняться повторно позднее.

Удаление профиля не удаляет ранее сохранённые резервные копии, переданные другим людям файлы, оригинальные фотографии из галереи и письма, отправленные в поддержку. Такими копиями пользователь и их получатели управляют отдельно.

При удалении Приложения или очистке его данных средствами операционной системы локальная информация может быть утрачена. Автоматическое восстановление гардероба с сервера разработчика не предусмотрено.

Разработчик не может дистанционно просматривать, изменять или удалять локальные гардеробы.

8. Внешние сайты и обращения в поддержку

При выборе пункта «Политика конфиденциальности» Приложение открывает эту страницу во внешнем браузере. Работа сайта и браузера регулируется условиями соответствующих сервисов.

При выборе пункта «Обратная связь» открывается почтовое приложение с адресом разработчика. Письмо не отправляется автоматически.

Если пользователь самостоятельно обращается к разработчику по электронной почте, указанные в письме сведения используются для рассмотрения обращения и ответа на него. Пользователь сам определяет содержание письма и его вложений.

Приложение не прикладывает к письму автоматически данные гардероба, фотографии или диагностические отчёты.

9. Безопасность данных

Доступ к локальным данным Приложения регулируется механизмами безопасности операционной системы устройства.

Приложение не предусматривает отдельной защиты входа паролем или биометрией и не шифрует экспортируемые ZIP-файлы.

Пользователю рекомендуется использовать блокировку устройства и самостоятельно обеспечивать сохранность передаваемых файлов и резервных копий.

10. Изменения политики

Разработчик может обновлять настоящую Политику при изменении функциональности Приложения или применимых требований законодательства.

Актуальная редакция размещается на этой странице.
